01 / TOOLKIT

Twelve tools. One case file.

Each utility is a rebuilt version of a familiar artifact viewer, extended with cross-referencing, signature checks, and bypass detection so nothing has to be reviewed in isolation.

Each "Live" tool below is a real, tested Python script you can download individually. They don't run themselves when downloaded — open a terminal in the folder you save it to and run python3 toolname.py (Python 3 required, nothing else to install). Double-clicking works too on most systems once Python is installed and associated with .py files.

02 / WORKFLOW

How a review actually runs.

Deepchecks doesn't replace judgment — it removes the blind spots a manual pass would miss.

1

Pull the artifacts

Run the relevant viewers — prefetch, MFT, SRUM, USB, saved files — to build a full timeline of what touched the system and when.

2

Cross-reference automatically

Each tool checks its findings against the USN journal and related artifacts, so a file removed from one source but still present in another gets caught.

3

Run signature and YARA checks

Every file surfaced is checked against built-in signature databases and YARA rules, plus any custom rule sets you've imported.

4

Flag what a cleaner missed

Built-in bypass detection highlights inconsistencies that indicate a log or artifact was cleared, so gaps in the record are visible instead of silent.

03 / COVERAGE

Built around the artifacts, not around trust.

Every tool in the suite is local-first and reads directly from disk and memory — no telemetry, no remote dependency for the core scan.

Disk

File & path layer

MFT, saved files, prefetch, and paths analysis together cover what was written to disk, when, and whether it still matches the journal's record of it.

Memory & process

Runtime layer

Kernel and user-mode RAM capture plus crash artifacts cover what was running, including traces that never touched disk at all.

Peripheral

Device layer

USB and device history cross-referenced against live ID databases, aimed at DMA and external-device bypass attempts.

Activity

Shell & network layer

PowerShell history and SRUM network usage round out the picture of what was executed and what it talked to.
